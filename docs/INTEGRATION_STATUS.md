## Navigation, player, queue and recording matching — 0.1.6 / code7

Implemented compact 56dp bottom navigation with full touch targets and without saved nested-stack restoration; repeated Home/Library/Search switching returns to the requested screen. Playlist reloads cancel stale jobs and keep the previous list visible. The player is an immersive artwork-first screen with its own seek/transport/like controls and a fully expanded Up next sheet. Queue entries traverse the controller's real shuffle/repeat-all timeline from the current occurrence, highlight/follow that occurrence and support jump, remove and clear-upcoming actions with stale-item guards. Saveable occurrence keys preserve duplicate song rows. New metadata chooses the largest trusted artwork; system bar contrast was corrected for the dark player.

Smart shuffle now seeds provider-related results from a specific recording, retains their ranking, excludes playlist/recent matches and interleaves one recommendation after each three playlist songs. The current song and position are retained where applicable, and a changed playback occurrence during lookup aborts. It has no unrelated artist-search fallback. Automatic recording matching is on by default in link import and available for existing imports. Title/credited artist/duration checks, clear local/Topic matches and consistent duplicate uploads can resolve automatically; conflicting versions require manual choice. Progress/cancellation remain usable while browsing. A guarded final transaction preserves ordered duplicates, retains original metadata and copies likes without deleting prior favorites. No schema migration or new dependency.

All five distinct data scenarios passed: four Room/backup/matching tests including stale-edit rejection and favorite preservation, plus a live Spotify-metadata-to-YouTube/related-results check. The three sampled Spotify songs all matched automatically; the selected recording returned 20 related items. This sample does not establish matching success for all 80 songs or recommendation quality.
