# Echo 0.2.4 / Android code15

This release adds public YouTube playlist-title search and public playlist-link preview/import on Android and Windows. It also makes the Windows upcoming-queue list scroll inside its compact picker.

## Included

- Search public YouTube playlist titles in the existing Search screen. Selecting a result opens the preview flow before importing.
- Preview and import public YouTube playlist links. Bounded continuation paging preserves available song order and duplicate occurrences; incomplete or unknown previews remain explicit before confirmation.
- Keep long Windows upcoming-queue lists scrollable inside the compact queue picker.
- Keep Spotify playlist import available through public share links and local playlist files. Spotify title search, audio playback, and automatic playlist synchronization are not included.
