## Changes

- Firebase library sync replaces Drive as the primary optional backend. Playlists, favorites, saved-track metadata and bounded listening history merge across Android and desktop. Audio, credentials and local file paths stay on their original device. First upload requires consent; automatic sync runs while the applications are open.
- Preserves ordered duplicates, concurrent playlist edits as conflict copies, unlike/delete markers and account-wide history-clear revisions. Release review also fixed metadata convergence and chronological history retention after remote imports.
- Windows provides desktop navigation, YouTube/local playback, Smart shuffle, queue editing, repeat, sleep timer, playlist import/matching, discovery, favorites/history and private offline downloads. Its icon matches Android.
- Windows checks published releases daily at startup and manually, independently of Android release ordering. Downloaded MSI size/digest and native product/version/architecture/upgrade identity are verified before explicit interactive installation.

## Installation and data

Android retains the original preview signing certificate so code10 can update in place. Do not uninstall or clear data. Android still requires normal installation permission and confirmation. Signing-certificate SHA-256: `c71752f76fa5e39cc5c653688e7abfdbf108900fd6334202f4e641b7884531ad`.

The Windows MSI installs per-user program files in `%LOCALAPPDATA%\EchoMusicDesktop`, separate from `%LOCALAPPDATA%\EchoMusic` library, credentials and downloads. A portable preview must be installed once with the MSI; future MSI upgrades update that installed copy. Windows Installer remains interactive. **The MSI is unsigned.**

Windows bundles a GPL-licensed Temurin Java 21 runtime and its legal files; matching complete runtime source is in the corresponding-source bundle. **64-bit VLC 3 is required separately** and is not bundled or installed silently. Desktop Google login currently requires importing the matching Desktop OAuth JSON privately; account availability depends on the project's consent/test-user configuration.
