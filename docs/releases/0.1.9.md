# Echo Music 0.1.9

Published **27 October 2026 (Asia/Kolkata)** as stable Android release **v0.1.9 / versionCode 10**. Package: `dev.echo.music`. Minimum Android: **8.0 / API 26**.

[GitHub release](https://github.com/addy1243/Echo/releases/tag/v0.1.9) · [Download APK](https://github.com/addy1243/Echo/releases/download/v0.1.9/EchoMusic-10.apk) · [Corresponding source](https://github.com/addy1243/Echo/releases/download/v0.1.9/EchoMusic-10-source.zip)

## Changes

- **Arrange the queue:** hold an upcoming song's drag handle and drop on another row. Edge dragging scrolls; Move up/down accessibility actions are available. Normal, shuffled and repeat-all queues preserve duplicates and current playback. Saved playlist order is unchanged.
- **Background downloads:** manual song and APK downloads continue after leaving Echo or turning the screen off, with progress/cancel notifications. Downloads shows received bytes and percentages when the source supplies a total. Song-download notification taps open Downloads.
- **Profile:** Google account/Drive playlist-sync controls, local playlist count and account device registrations checked during the last successful sync. Registrations do not indicate online presence; the count is unknown before successful sync.
- **Update installation:** verified downloads offer Install update through user action. Android's installation permission/confirmation remains required. Notification navigation waits for the app navigation graph to be ready.

## Update instructions

1. Open **Settings → Check for updates → Update app**, or download the APK above.
2. Keep Echo open for this initial download if the installed older version requires it. Background download behavior is available after installing 0.1.9.
3. Follow Android's installation prompts. If permission is requested, allow updates from Echo, return and tap **Install update** again.
4. Use an in-place update with the original signing certificate. Do not uninstall or clear app data to force an update. Notification permission controls notification visibility.

## Known limits

- Force-stop, process termination, reboot and Android/OEM limits can interrupt downloads. Retry starts from the beginning; range resume is not implemented. Automatic frequent-song caching retains existing app/playback-process and unmetered-network rules.
- Sign-in success does not prove Drive sync. Audio, likes, history, credentials and local file paths do not sync. Local libraries remain device-wide after sign-out; unseen stale snapshots can restore deletions without global tombstones.
- Phone/OEM/Doze and metered-network reliability, car behavior and normal system-installer completion were not established by emulator checks. Provider availability and artwork quality remain source-dependent.
- Desktop development is a separate workstream, excluded from this Android APK and release claims.
