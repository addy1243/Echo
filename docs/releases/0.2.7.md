# Echo 0.2.7 / Android code18 and Windows 0.2.7

Published [Echo 0.2.7](https://github.com/addy1243/Echo/releases/tag/v0.2.7) from tag `v0.2.7`, commit `1222d03d284b9d1a234b369ca504617ec9f7ca84`. Earlier tags and release assets remain immutable. The release source is the tagged commit, not later documentation changes.

## Included

- First-run tutorial, appearance and background settings, Windows single-instance startup, playback shortcuts and player symbols.
- Spotify account-data ZIP snapshots stored encrypted on the device, with supported listening history, saved artists and albums available locally.
- Single YouTube video URL search, bounded Mix previews and optional refresh for complete linked YouTube playlists.

## Executed checks

- GitHub public asset metadata matched the artifact sizes and SHA-256 digests. The corresponding-source archive passed CRC verification and identifies the exact source commit.
- Shared and Android unit tests, Android release build and lint, and the desktop test suite passed. A focused linked-playlist repository test and tutorial tests passed on an Android emulator. Windows Stage displayed the tutorial screenshot and scrolled Settings to the Spotify controls.
- The release APK passed alignment and v2/v3 signature checks and matched the existing signing identity. It installed over the existing emulator app without clearing data and launched as version 0.2.7/code18. This is not full UI acceptance.
- The MSI passed native product, version, x64 and upgrade-identity inspection. The public Windows updater helper from baseline 0.2.6 discovered 0.2.7, downloaded the exact MSI and verified its byte count, digest and native identity. The helper did not launch the installer.

## Remaining acceptance

The real installed Windows app has not completed the in-app download, interactive installation, restart and library/DPAPI preservation checks. Computer Use was stopped by the user during that acceptance. Native keyboard behavior, live Spotify and YouTube import/playback, and real connected-device behavior remain unverified for this release. Publication and helper checks do not establish end-to-end updater or runtime acceptance.
