# Echo 0.2.6 / Android code17 and Windows 0.2.6

Source tag: `v0.2.6-final`, commit `abd447088f1791f650cd57c8cec7bdd51b4030ed`. The earlier `v0.2.6` draft was withheld after a first-run Windows credential persistence failure. The corrected packages retain version 0.2.6. Both app updaters use asset versions, so the tag suffix does not alter update selection.

## Included

- Rounded Windows Now Playing panel, inline volume, right queue sidebar with artwork, and player and queue transitions.
- Playlist previews load automatically from search on Android and Windows. YouTube can show its first page while loading the remainder. Spotify link and file drafts try up to 25 unique matches and require confirmation to save.
- Windows includes validated Desktop public-client configuration. New profiles can start Google sign-in from Devices & account. A protected credential save now keeps the Firebase project paired with the bundled client ID. The import button is hidden when manual setup is unnecessary.

## Executed checks

- Core, desktop and Android app unit tests passed. Android instrumentation sources compiled. The Android release build and lint passed.
- The signed Android APK passed alignment, package and version checks, v2/v3 signature verification, and matched the 0.2.5 signing certificate. Its Android, data, core and playback sources match the final tagged source.

The final first-save regression wrote and reloaded an isolated DPAPI record without persisting the bundled client value in it.

## Limits

- The packaged preview showed the fresh-profile sign-in button enabled before the first-save correction. The final fix was exercised through the DPAPI regression. Live browser sign-in and the interactive MSI install/restart were not run against the final release.
