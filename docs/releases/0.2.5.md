## Included

- A focused multi-device player: Windows uses the device card deck, Android uses the compact swipeable player. Song and playlist requests route to the selected independent device.
- Play together includes session-bound network timing estimates, common scheduled starts, a Sync action, and guarded shared-queue replacement. Missing or warming-up estimates use an 8-second fallback. This does not guarantee sample-accurate acoustic synchronization.
- Transient playback retries retain the current occurrence and position; retries stop after pause, track change or app quit.
- Windows close-to-tray playback and Android MediaLibraryService background playback.
- Stage-only simulated devices and Admin controls. Android release DEX contains none of the Stage/Admin labels; Windows production entry point always uses non-staging mode.
