## Evidence and limits

Core, data, Android playback/app and desktop unit suites, Android release build and lint passed. The APK matched Echo's existing signer and installed over 0.2.7 on a dedicated emulator; the upgraded app launched. The MSI passed product, version, x64 and stable UpgradeCode checks. The source archive passed CRC and commit verification. GitHub's asset sizes and digests matched; public APK and MSI downloads were hashed, and source availability and checksum metadata were checked.

The public updater helper from Windows 0.2.7 downloaded and verified the MSI. The installed Windows 0.2.7 app also discovered, downloaded and verified it, reaching the **Install update** button. Interactive installation, restart, library and DPAPI preservation have not been checked. Android process-death recovery, artwork, Bluetooth and native Windows keyboard behavior also remain unverified in runtime acceptance. The release tag is immutable; later documentation changes do not alter its source.
